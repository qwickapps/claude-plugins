# QwickApps Claude Plugins

Official plugin marketplace for QwickApps development.

## Install

```
/marketplace add qwickapps/claude-plugins
/plugins install qwickapps-ux-design
```

## Plugins

- **qwickapps-ux-design** — Enforces `@qwickapps/react-framework` usage and `--theme-*` CSS variables. Replaces the official `frontend-design` skill with a QwickApps-aware version that maintains full creative freedom while routing all implementation through the design system.
